# Lunar Mass Driver Launch Calculator

## Files

- `massDriverCalc.html` — page markup
- `massDriverCalc.css` — this calculator's own styling; the layout comes from the shared frame
- `massDriverCalc.js` — the calculator logic

## Dependencies

Uses `../../Shared/calc-frame.css` (layout) and `../../Shared/calc-about.js`
(the "About this calculator" pop-up); the folder needs `Website/Shared/` beside
it. The calculation itself imports nothing.
